# Siegers ホームページ 機能一覧と推移

草野球チーム「小雀シーガーズ（Siegers）」のホームページが持つ機能の一覧と、それぞれがいつ・どう変わってきたかをまとめたもの。

- 更新日: 2026-10-29
- 推移は git のコミット履歴から整理している。日付はコミット日
- 要件・設計の詳細は [requirements/current-state.md](requirements/current-state.md)・[design/current-state.md](design/current-state.md) を参照

---

## 1. 現在の機能一覧

### 1-1. 公開ページ（誰でも閲覧可）

| パス | 画面 | 主な機能 |
|------|------|------|
| `/` | Top | ヒーロー画像・チーム紹介、選手成績カード（ホバー／スマホは常時「選手成績を見る」表示）、最近の試合スコア |
| `/about` | 小雀シーガーズとは | チーム紹介 |
| `/games` | 試合結果 | 試合一覧。年度で絞り込み、対戦相手は部分一致の検索で絞り込み、20 試合ごとのページ送り。スマホは「先攻｜球場・スコア・勝敗｜後攻」の 3 列表示、PC は表 |
| `/games/[id]` | 試合詳細 | イニングスコア（7 回が基本、延長した回だけ追加。裏の×・サヨナラの x 表示）、打撃成績・投手成績。スマホはバナー内に計・安・失つきのイニングスコア、成績は打者／投手のタブと「詳しい成績を見る」の切替。試合結果一覧への戻るリンク、選手の詳細成績への遷移。ログイン中は編集・削除ボタン |
| `/players` | 成績 | 4 タブ構成（下表）。年度・試合種別・対戦相手・大会名・期間・選手名で絞り込み、規定打席／規定投球回で絞り込み（既定は規定あり）。チーム内順位を背景色で表示、列ソート、横スクロール + 選手名列固定 |
| `/players/[id]` | 選手詳細 | 打撃成績・投手成績（年度別・通算、チーム内順位の背景色）、もうすぐ達成の記録、獲得タイトル、継続中の連続記録 |
| `/news` | News 一覧 | タイトル中心の一覧、10 件ごとのページ送り |
| `/news/[id]` | News 詳細 | 記事本文。ログイン中は編集・削除 |

| タブ | 内容 |

| 打撃 | 試合数・打率・打席・打数・安打・本塁打・打点・得点・盗塁・出塁率・長打率・得点圏打率・OPS・ISO・二塁打・三塁打・塁打数・三振・三振率・四球・死球・犠打・犠飛・併殺打・敵失・失策・盗塁阻止・出席率 |
| 投手 | 登板・勝・H・S・敗・勝率・防御率・投球回・投球数・失点・自責点・完投・完封・被安打・被本塁打・奪三振・与四球・与死球・ボーク・暴投・奪三振率・与四球率・K-BB・WHIP |
| チーム | 年度別・合計の試合数・勝敗（その他の試合があれば「他」列）・勝率・打席・長打率・四球率・三振率など。既定は全年表示 |
| 通算記録室 | もうすぐ達成の記録（カード表示・残りが少ない順）、達成済みの記録（年度選択・達成順）、歴代シーズン記録、連続試合記録（出場・安打・出塁・出塁（敵失含む）・盗塁・打点・得点・失策・三振・登板・勝利） |

#### 選手詳細の記録系

- **もうすぐ達成**: 試合数・打席・安打・本塁打・打点・得点・盗塁・二塁打・三塁打・塁打数・四球・登板・勝利・ホールド・セーブ・奪三振・投球回の節目
- **獲得タイトル**: 年度ごとの公式戦でのチーム内 1 位。首位打者・本塁打王・打点王・最多安打・最高出塁率・盗塁王・最多勝利・最優秀防御率・最多奪三振・最高勝率・最多セーブ（率系は規定到達者のみ、最高勝率は 5 勝以上）
- **継続中の連続記録**: 現在も続いている連続試合記録（期間の開始位置を揃えて表示）

### 1-2. 管理者ページ（ログイン必須）

| パス | 画面 | 主な機能 |
|------|------|------|
| `/admin/login` | ログイン | メールアドレス + パスワード（Supabase Auth） |
| `/admin/games/new` | 試合結果入力 | フォーム入力 / JSON 入力 / JSON ファイルの一括登録。試合種別（公式戦・練習試合・その他）は大会名から自動判定 |
| `/admin/games/[id]/edit` | 試合結果編集 | 試合情報・成績の編集。試合結果（勝・負・分・その他）の手動選択 |
| `/admin/players` | 選手管理 | 一覧・投手フラグ切替・削除 |
| `/admin/players/new` | 選手登録 | |
| `/admin/opponents` | 対戦相手マスタ | 追加・名前変更・削除。既存の名前に変更すると統合 |
| `/admin/tournaments` | 大会名マスタ | 同上 + 試合属性（公式戦・練習試合・その他）の設定 |
| `/admin/news/new`・`/admin/news/[id]/edit` | News 投稿・編集 | |
| `/admin/settings` | 設定 | 規定打席・規定投球回の倍率（小数可）、成績ページの既定表示（年度・試合種別） |

### 1-3. 横断的な機能

- **入力チェック**: 成績に矛盾（安打 < 長打の合計など）があると保存できない。スコアと食い違う試合結果は警告を確認したうえで保存できる
- **データ更新日時**: フッターに成績データの最終更新日時を表示
- **フッター**: 連絡先メールアドレス
- **PWA 対応**: manifest とアイコン（ホーム画面への追加）、タブのアイコン・タイトル
- **操作感**: 画面遷移中は画面中央にスピナー、ボタン押下時の縮むアニメーション、スマホでのタップ反応
- **スマホ対応**: 全画面。成績表は横スクロール + 選手名列固定、通算記録室はリスト表示・セクションナビ
- **認可**: 未ログインで `/admin/*` に入ると `/admin/login` へリダイレクト。DB は RLS で「閲覧は全員・書き込みは認証済みのみ」
